Datenschutz

Stand: 4. Oktober 2026. English version.

1RM Planner erhebt keine Daten über dich. Es gibt kein Konto, keine Analyse, keine Werbung und keinen Code von Dritten, der etwas übermittelt.

Was auf deinem iPhone bleibt

Deine Übungen, Einheiten, eingetragenen Sätze, Trainingsblöcke und Einstellungen werden nur auf deinem iPhone gespeichert. Sie werden gelöscht, wenn du die App löschst. Die Backups deines iPhones (iCloud oder Computer) können sie enthalten, wie bei jeder App, unter deiner Kontrolle.

Mitteilungen

Der Hinweis am Ende der Pause ist eine lokale Mitteilung. Sie wird auf deinem iPhone geplant und nie über einen Server verschickt.

Deinen Aufbau in Worten beschreiben

Die Kurzschreibweise liest die App selbst. Freien Text liest Apples Sprachmodell auf dem Gerät (Apple Intelligence). Die App sendet deinen Text weder an Apples Server noch an Private Cloud Compute noch an sonst jemanden.

Export

Der CSV-Export verlässt dein iPhone nur, wenn du ihn selbst teilst.

Betatest

Wenn du die App über Apples TestFlight testest, teilt Apple mit dem Entwickler, was TestFlight teilt: Absturzberichte, das Feedback, das du schickst, und, wenn du per E-Mail eingeladen wurdest, deinen Namen und deine E-Mail-Adresse. Diese Daten werden nur genutzt, um die App zu verbessern und Fehler zu beheben.

Kontakt

Eine Kontaktadresse für Fragen zum Datenschutz folgt in Kürze.
